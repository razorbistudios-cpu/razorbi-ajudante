# Ajudante de lançamentos (Razorbi)

Instalador do Ajudante do TOTVS. Baixe a versão mais recente em
[Releases](https://github.com/razorbistudios-cpu/razorbi-ajudante/releases/latest)
ou pelo botão **Baixar Ajudante** no site.

Este repositório guarda só os instaladores; o código fica em repositório privado.
